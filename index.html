Featured Research & Publications

Web-TEMPEST: In-Browser VHF RF Transmission via Monitor EMI

Side-Channel Analysis TEMPEST HTML5 Canvas VHF (~148.5 MHz)

An open-source proof-of-concept demonstrating electromagnetic side-channel radiation generated entirely within an unprivileged web browser. By modulating monitor pixel clock frequencies using high-frequency rendering loops, standard display interfaces emit unintentional RF signals receivable as VHF Morse code on unmodified handheld transceivers.

  • Defense Featured in the UK NCSC CTO Weekly Briefing by Ollie Whitehouse
  • News Hackaday Feature · RTL-SDR.com Coverage
  • DOI Zenodo Open Research Archive (10.5281/zenodo.22307838)
  • Code GitHub Repository & Interactive PoC

Class-D RF Covert Transmitter: Physical-Layer Air-Gap Exfiltration

Hardware Security Physical-Layer Exfiltration Android AudioTrack PWM Harmonics

Experimental hardware security research demonstrating zero-permission covert RF transmission using commodity smartphone internal audio hardware. Modulates Class-D amplifier high-current PWM switching harmonics to leak detectable RF comb spectrums across VHF (144.000 MHz), demodulated as CW on standard handheld radios.

  • DOI Archival Record: CERN Zenodo (DOI: 10.5281/zenodo.23082466)
  • Code Source Code & Technical Analysis (Android / Low-Level Audio)
